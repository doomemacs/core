*This module is hardcoded to be enabled until v3 is released.* Its flags can't
be customized yet, but are documented here as a reference for posterity.

Also, because this is a compatibility module, its packages will rarely be bumped
(except to resolve upstream breakage) and it won't be developed to support new
features. If you need newer versions, I recommend you install the package
manually instead of relying on this module!
#+end_quote

* Description :unfold:
This module provides backwards compatibility with v2 of Doom's core. It
reinstates old APIs, variables, packages, and configuration that are slated for
removal in v3. This exists to give you more time to adapt to the changes.

For a full table of what's been changed and what to use instead, see the Usage
section below.

** Module flags
- -better-jumper ::
  Don't install or configure [[pkg:better-jumper]].
- -general ::
  Don't install [[pkg:general]] and don't provide the [[fns:map!]] macro.
- -projectile ::
  Don't install or configure [[pkg:projectile]].
- -smartparens ::
  Don't install or configure [[pkg:smartparens]].
- -use-package ::
  Don't install or configure [[pkg:use-package]], or define [[fns:use-package!]] or
  [[fns:use-package-hook!]].

** Packages
- [[package:better-jumper]] unless [[module:-better-jumper]]
- [[package:general]] unless [[module:-general]]
- [[package:projectile]] unless [[module:-projectile]]
- [[package:smartparens]] unless [[module:-smartparens]]
- [[package:use-package]] unless [[module:-use-package]]

released, this can't be changed.
